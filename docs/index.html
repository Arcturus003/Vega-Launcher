Download for Windows View Source Code

Built for Speed & Reliability

Everything you need for clean Minecraft installations without setup friction.

⚡

Native Modrinth Browser

Search, filter, and install popular modpacks, individual mods, and shaderpacks directly inside the launcher without opening a web browser.

☕

Zero-Friction Java Setup

Vega Launcher detects version requirements (Java 8, 17, or 21) and downloads Mojang's official minimal JRE runtime automatically when needed.

⚙️

Multi-Loader Support

First-class integration for Fabric, Quilt, Forge, and NeoForge mod loaders with instant RAM preset allocation (4 GB, 6 GB, 8 GB).

📁

Isolated Instances

Each profile operates in its own dedicated directory. Your mod versions, world saves, resource packs, and configs never conflict.

🛡️

Windows DPAPI Security

Genuine Microsoft OAuth session tokens are encrypted at-rest using native Windows Data Protection API (DPAPI) for maximum local security.

🎨

Obsidian Dark Aesthetics

Sleek dark surfaces with 5 customizable accent themes (Electric Amethyst, Ender Pearl, Nether Crimson, Emerald Lush, Deep Dark) and procedural audio.
