Built for Speed & Reliability Hız ve Güvenlik İçin Tasarlandı

Everything you need for clean Minecraft installations without configuration friction.

Ayar karmaşası olmadan temiz bir Minecraft deneyimi için gereken her şey tek yerde.

⚡

Native Modrinth Browser Dahili Modrinth Tarayıcısı

Search, filter, and install modpacks, mods, and shaders directly inside the client without opening a web browser.

Tarayıcı açmadan doğrudan istemci içinden mod paketlerini, modları ve shaderları arayın ve tek tıkla kurun.

☕

Automated Java Setup Otomatik Java Kurulumu

Automatically detects loader version requirements (Java 8, 17, or 21) and downloads Mojang's official minimal JRE runtime.

Seçtiğiniz sürümün ihtiyacını (Java 8, 17, 21) tespit ederek resmi Mojang mini-JRE çalışma zamanını otomatik kurar.

⚙️

Mod Loader Support Tam Yükleyici Desteği

First-class integration for Fabric, Quilt, Forge, and NeoForge with 1-click RAM presets (4 GB, 6 GB, 8 GB).

Fabric, Quilt, Forge ve NeoForge için doğrudan destek; hızlı tek tık RAM ayarları (4 GB, 6 GB, 8 GB).

📁

Isolated Profiles İzole Profil Mimarisi

Each profile keeps its own worlds, mods, and configs separated in independent directories. Zero mod conflicts.

Her profil kendi dünyalarını, modlarını ve ayarlarını bağımsız klasörde tutar. Mod çakışmalarını tamamen önler.

🛡️

Windows DPAPI Security Windows DPAPI Koruması

Microsoft OAuth tokens are encrypted locally on disk using Windows Data Protection API (DPAPI). Passwords are never stored.

Microsoft OAuth oturum jetonları Windows DPAPI ile yerel olarak şifrelenir. Şifreniz asla diskte düz metin tutulmaz.

🎨

Obsidian Dark Aesthetics Obsidyen Koyu Arayüz

High-contrast obsidian surfaces with 5 selectable accent themes and real-time synthesized procedural audio feedback.

Göz yormayan obsidyen yüzeyler, 5 farklı vurgu teması ve matematiksel frekans sentezli prosedürel ses efektleri.
